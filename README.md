## Features

- Venue okx / BTCUSDT
- Strategy id grid
- Paper engine and stub candles
- Risk cap on notional / equity

## Prerequisites

- Go 1.22+
- Git

## Getting Started

```bash
git clone <repo-url>
cd okx-v5-bot
make build
./bin/okxv5 -help
```

## CLI Usage

```bash
make test
go run ./cmd/okxv5 -help
```
